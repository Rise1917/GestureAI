# GestureAI

Django веб-приложение для распознавания жестов с использованием AI.

## Возможности

- Регистрация и авторизация пользователей
- Профиль пользователя с аватаром
- Распознавание жестов через камеру
- История распознанных жестов
- Поиск видео по жестам

## Установка

1. Клонируйте репозиторий
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Выполните миграции:
```bash
python manage.py migrate
```

4. Создайте суперпользователя:
```bash
python manage.py createsuperuser
```

5. Запустите сервер:
```bash
python manage.py runserver
```

## Структура проекта

- `accounts/` - приложение для управления пользователями
- `main/` - основное приложение с функционалом распознавания жестов
- `static/` - статические файлы (CSS, JS, изображения)
- `templates/` - HTML шаблоны
- `media/` - загружаемые файлы пользователей

## Технологии

- Django 5.2.3
- SQLite
- JavaScript (ONNX для AI)
